# Contributing Guide

## Getting Started
1. Fork the repository
2. Clone: `git clone https://github.com/YOUR_USERNAME/PROJECT.git`
3. Install: `npm install`
4. Setup DB: `npx prisma db push && npm run db:seed`
5. Dev server: `npm run dev`

## Pull Requests
- Branch from `main`
- Follow existing code style (TypeScript, Tailwind CSS)
- Test your changes with `npm run build`
- Open a PR with a clear description

## Code Style
- TypeScript strict mode
- Tailwind CSS for styling
- Next.js 14 App Router conventions
